# TSS Fixtures Strategy

Export only TSS-owned presentation and setup artifacts.

## Keep as fixtures

- `Print Format`
- `Workspace`
- `Property Setter`
- `Client Script`

## Do not fixture

- GBase roles
- GBase role profiles
- GBase users
- `Base Company`
- `Staff`

## Seed through setup instead of fixtures

- `Transport Settings` singleton
- Optional sample `Vehicle Inspection Checklist Item` rows if the client wants a starter checklist
